# JudgesPro — Universal Judging & Evaluation System

**JudgesPro** is a digital judging and evaluation system designed for events, competitions, exhibitions, performances, presentations, and other evaluation activities.

## 📱 Download JudgesPro

**JudgesPro v1.0.0**

[Download JudgesPro APK](https://github.com/surendranaduthila-lab/JudgesPro-Download/releases/latest/download/JudgesPro.apk)

The Android APK is distributed through GitHub Releases.

## ✨ Features

* Admin and Judge workflows
* Item and participant management
* Judge profile and item selection
* Digital judgement entry
* Photo and video support
* Automatic result tabulation
* Multiple-judge result management
* Result viewing and printing
* PDF export
* JSON data export/import
* CSV item import
* Offline-friendly operation

## 📥 Installation

1. Download the latest `JudgesPro.apk`.
2. Open the downloaded APK on your Android device.
3. If Android asks for permission to install apps from this source, allow it.
4. Install JudgesPro.
5. Open the application.
